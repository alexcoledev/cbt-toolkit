How to Use These Free CBT Tools

  1. Pick a category that matches what you are struggling with. If you are not sure, start with Core Tools.
  2. Open any tool — no signup, no download required. Each tool works in your browser immediately.
  3. Follow the instructions on the page. Most tools take 10 to 20 minutes to complete.
  4. Practice regularly. CBT works through repetition. Aim for daily or 3x weekly sessions for 8 to 12 weeks.
  5. Download the full toolkit if you want offline access or to host it yourself. Available as a ZIP release on GitHub.

Frequently Asked Questions

Are these CBT tools really free?

Yes. All 36 tools are free and open-source under the MIT license. No signup, no email required, no paywall, no trial period. You can use them immediately in your browser or download the full toolkit as a ZIP file from GitHub. An optional $1 supporter option exists for those who want to help keep them free, but it is entirely optional and not required to access any tool.

What CBT tools are included?

The directory includes 36 tools organized into 7 categories: anxiety tools (8), depression and mood tools (5), work and productivity tools (11), sleep tools (1), emotions and self tools (7), core CBT tools (8), and educational guides (4). Each tool is a standalone web page with exercises, worksheets, or interactive elements.

Do I need to install anything to use these tools?

No. All tools run in your web browser. No installation, no app download, no account creation. You can also download the entire toolkit as a ZIP file and run it locally or host it yourself. The tools are static HTML files that work offline once downloaded.

Can I use these CBT tools without a therapist?

Yes. The tools are designed for self-help use with clear instructions. Research shows self-guided CBT is effective for mild to moderate anxiety, depression, and stress. However, for severe symptoms, trauma, or crisis, please work with a licensed therapist. The tools can also be used alongside professional therapy.

What is the best free CBT tool to start with?

If you are new to CBT, start with the Thought Record Template. It is the single most used CBT exercise and teaches the core skill of identifying and restructuring automatic thoughts. If you know your specific concern (anxiety, depression, procrastination), go directly to the category page for targeted tools.

Can I share or modify these CBT tools?

Yes. The toolkit is open-source under the MIT license. You can share, modify, distribute, and even use it commercially. Fork the GitHub repository to customize tools for your own needs. Attribution is appreciated but not required.
